# Malaysian Automatic Number Plate Recognition (ANPR)

A deep learning-based Automatic Number Plate Recognition (ANPR) system for Malaysian vehicles using **YOLOv8** for license plate detection, **CRNN** for Optical Character Recognition (OCR), and a **JPJ compliance checking** module.

---

## 📌 Project Overview

This project is developed as my Final Year Project (FYP).

The system performs the following tasks:

- Detect Malaysian vehicle license plates using YOLOv8
- Crop detected license plates
- Recognize license plate characters using CRNN
- Validate detected plate numbers
- Perform JPJ compliance checking
